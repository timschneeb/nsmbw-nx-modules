# NSMBW Switch modules

Standalone runtimes, resources and debug symbols for the NSMBW Switch launcher.

Install the launcher from [timschneeb/nsmbw-nx](https://github.com/timschneeb/nsmbw-nx)
using `NSMBW-switch.zip`. The launcher downloads these files itself and keeps them in
`/switch/nsmbw/`; they are not meant to be copied by hand except when debugging.

Every release uses the same version as the main launcher release.

## Release assets

- `launcher.nro` - launcher self-update payload
- `vanilla-game.nro` - vanilla runtime update payload
- `vanilla-debug-symbols.zip` - vanilla crash symbols
- `newersmbw-game.nro` - Newer runtime
- `newersmbw.romfs.zst` - compressed Newer resource image
- `newersmbw-banner.png` - Newer catalogue banner
- `newersmbw-debug-symbols.zip` - Newer crash symbols
